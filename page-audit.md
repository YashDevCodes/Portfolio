## Structure and Accessibility

- The document language is set to English using `lang="en"`.
- The viewport meta tag is included for responsive layouts.
- The page uses a single main heading followed by section headings.
- Navigation links point to the Home, About, Skills, Projects, and Contact sections.
- Buttons have accessible labels where needed.
- Keyboard focus styles are defined using `:focus-visible`.
- A reduced-motion preference is supported in the CSS.
- The initials "YD" are used as a decorative profile element instead of an unprovided photograph.

## JavaScript Functionality

The `script.js` file provides the following features:

1. Displays the current year automatically in the footer.
2. Switches between dark and light themes.
3. Saves the selected theme in browser local storage when available.
4. Opens and closes the mobile navigation menu.
5. Closes the mobile menu when a navigation link is selected.

These features must be tested in the browser to confirm that they work correctly.

## Styling and Responsive Design

- CSS custom properties are used for theme colours.
- The default design uses a modern dark theme.
- A light theme is available through the theme toggle.
- Cards and buttons include hover effects.
- Responsive media queries adjust the layout for smaller screens.
- The skills and projects sections use grid layouts.
- A reduced-motion media query is included.
